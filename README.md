# MEITI Free Apps

Apps completas generadas por la forja de [MEITI](https://meiti.dev): frontend en React, backend
propio con SQLite, y builds de escritorio (Windows, Mac, Linux) y móvil (Android, iOS). Gratis, con
licencia MIT, una por repo para usarlas como plantilla.

> ⚠️ **Tal cual las generó la IA, con bugs reales.** Se publican sin retoques a mano y pueden
> tener errores de verdad. Sirven para probar [Healer](https://meiti.dev/healer), que encuentra y
> repara esos bugs. *As generated by AI, with real bugs.* Ver [DISCLAIMER.md](DISCLAIMER.md).

| App | Qué es |
|---|---|
| [TablerosNorte](https://github.com/meiti-dev/TablerosNorte) | Tableros de tareas tipo kanban, con columnas y tarjetas |
| [FaroWiki](https://github.com/meiti-dev/FaroWiki) | Wiki interna para documentar procesos de un equipo |
| [RiberaChat](https://github.com/meiti-dev/RiberaChat) | Chat de equipo con canales, para un estudio contable |
| [MisTareas](https://github.com/meiti-dev/MisTareas) | Lista de tareas personal |
| [NexoCRM](https://github.com/meiti-dev/NexoCRM) | CRM de ventas con contactos y embudo de oportunidades |
| [UrbanaRopa](https://github.com/meiti-dev/UrbanaRopa) | Tienda en línea de ropa |
| [CafeGranoPOS](https://github.com/meiti-dev/CafeGranoPOS) | Punto de venta para una cafetería |
| [LinguaLearn](https://github.com/meiti-dev/LinguaLearn) | App para aprender idiomas con lecciones y práctica |
| [EstanciasDelSur](https://github.com/meiti-dev/EstanciasDelSur) | Reservas de alojamientos de temporada |
| [AgendaSonrie](https://github.com/meiti-dev/AgendaSonrie) | Agenda de turnos para una clínica dental |

## Cómo usar una

1. Abre el repo de la app y elige **Use this template**.
2. Sigue el README de esa app para correrla en local.
3. Para que Healer la revise en cada push, crea una API key en [meiti.dev/healer](https://meiti.dev/healer)
   y guárdala como secret `HEALER_API_KEY`.
